# Sources de données

Chaque connecteur ou dataset doit documenter : propriétaire, URL, licence/CGU, autorisation d'extraction, périmètre des sports et marchés, fraîcheur, quota et prix, schéma, fuseaux horaires, limites et politique d'archivage.

**Aucune clé API, aucun token ni donnée personnelle dans Git.** Stocker les secrets dans l'environnement d'exécution.
