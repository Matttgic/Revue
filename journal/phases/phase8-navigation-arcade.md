# Phase 8 — trois écrans utiles dans Revue Arcade

- **À JOUER** : matchs et sélections expérimentales, prix archivés
  explicitement non jouables et lien d'explication par rencontre.
- **POURQUOI** : page dédiée, filtres, recherche, même données
  horodatées/contrôles que l'accueil. Paramètres `league` et `id`
  vérifiés, jamais de correspondance de match inventée.
- **BILAN** : les gains, pertes, ROI et en attente des simulations papier
  sont visibles en premier ; qualité des modèles dans MODE AVANCÉ.
- **LAB** : toutes les pages techniques conservées, filtrage local.
- Accueil accessible via la marque ; menu unique trois écrans sur
  Android/ordinateur, défilement tactile, décor CSS 3D et reduced-motion.
- Tests dans workflow Arcade et pré-publication GitHub Pages.
- Pas d'altération des modèles, probabilités, historiques pré-match,
  cotes, résultats, pas d'appels API payants, pas d'EV ou pari réels
  inventés. Un design neuf n'augmente pas la fidélité au modèle source.
