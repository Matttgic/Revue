Qualité des modèles

Tests historiques chronologiques de Brier et log loss, par compétition.

Pas un bilan de gains. Ces tests utilisent les scores archivés, pas les cotes réelles obtenables. Pas de calcul de ROI ni de comparaison aux bookmakers. Les échantillons sont incomplets et certaines compétitions affichent trop peu de matchs.

Comprendre les chiffres

Brier : erreur quadratique moyenne entre probabilité annoncée et résultat. Plus bas = mieux. Pour le football 1N2, somme sur les trois issues ; pour les sports à deux issues, une seule probabilité.

Log loss : pénalise particulièrement les prédictions très sûres mais fausses. Plus bas = mieux.

Référence uniforme : toujours 50 % pour deux issues ou 33,3 % pour 1N2. C'est un contrôle très simple, pas la référence de marché. Même un modèle meilleur que cette référence n'est pas nécessairement rentable.
