ÉCARTS DE COTES.

Lecture automatique des cotes françaises déjà récupérées par PulseScore. Une couverture mathématique exige toutes les issues du même match, avec le même règlement, des prix horodatés et plusieurs bookmakers. Le scanner ne consomme aucun appel API supplémentaire.
