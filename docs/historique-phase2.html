NOTRE HISTORIQUE.

Les prévisions et les probabilités sont enregistrées une seule fois avant le coup d’envoi. Les résultats proviennent des scores finaux observés par ESPN. Le classement Elo est reconstruit uniquement avec les matchs terminés depuis le démarrage réel de cet historique.

Historique prospectif indépendant : aucune prédiction historique inventée, aucune importation du SQL Clairvoyance. Les probabilités sont expérimentales, sans calibration ou avantage démontré. Les compétitions NHL, MLS et UCL relèvent de suivis distincts tant que les règles de prolongation ne sont pas pleinement comparables. Aucun pari réel n’est placé.
