# Stratégies par sport et par marché

Dossiers prévus : `football/`, `tennis/`, `basketball/`, `hockey-nhl/`, `baseball/`, `multisports/`, `transversales/`.

Chaque stratégie admise possède une fiche à partir de `templates/FICHE_STRATEGIE.md`, sa version source, du code isolé quand cela est légal, et des tests reproductibles quand réalisables.

**Important :** une stratégie documentée ou simulée n'est pas automatiquement gagnante.
