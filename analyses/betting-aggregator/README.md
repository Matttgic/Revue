# ixbogotaix-ops/betting-aggregator

Ce dossier conserve l’audit de l’agrégateur FastAPI/React, son approche de collecte multi-source et les limites de son score de consensus. Aucun code source ni aucune donnée n’ont été intégrés aux modèles Revue.

- [Audit technique et avis](AUDIT.md)
- [Enseignements transversaux](../../catalogue/ENSEIGNEMENTS.md)

**Mon avis :** le concept de réunir pronostics, cotes et sources dans une interface est intéressant pour surveiller le marché. En revanche, ce dépôt attribue des performances non vérifiées à ses sources, recompte le choix bookmaker sous une autre identité et génère des arguments factuels sans données. Je le garderais comme étude de cas, pas comme modèle exploitable.
