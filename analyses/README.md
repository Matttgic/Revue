# Analyses de dépôts

Un audit centralise les informations de chaque dépôt examiné, à partir de [`templates/FICHE_SOURCE.md`](../templates/FICHE_SOURCE.md). Les dossiers `Stat-Seer/`, `Betting-Dashboard/`, `nba-betting/`, `NBA-Machine-Learning-Sports-Betting/`, `nhl-savant/`, `sports-betting-toolbox/`, `sports-betting-sportsbook/`, `sports-betting/`, `BeatTheBookie/`, `ProphitBet-Soccer-Bets-Predictor/`, `pretrehr-Sports-betting/`, `llSourcell-ChatGPT_Sports_Betting_Bot/`, `edouardthom-ATPBetting/`, `WagerBrain/`, `nfl-betting-model/`, `wowza-betting/`, `betting-aggregator/`, `sports-model/`, `sports-prediction-model/` et `nfl-sports-betting/` regroupent chacun leur audit et leurs fiches; les autres audits restent sous forme de fichiers dédiés. Chaque audit précise aussi ce que la source confirme, complète, contredit ou ajoute par rapport aux idées déjà cataloguées. Une analyse peut retenir une idée **sans** reprendre le code. Elle doit préciser ce qui est testé, ce qui est supposé, les risques de fuite temporelle, la licence et la décision. Les enseignements étayés par plusieurs sources sont cumulés dans [`catalogue/ENSEIGNEMENTS.md`](../catalogue/ENSEIGNEMENTS.md). Les dépôts rejetés restent ici, pour ne pas les réexaminer.
