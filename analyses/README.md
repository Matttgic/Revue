# Analyses de dépôts

Un fichier `AAAA-MM-JJ_owner_repo.md` par dépôt examiné. Dupliquer `templates/FICHE_SOURCE.md`.

Il est possible de retenir une idée **sans** reprendre le code. Noter précisément : ce qui est testé, ce qui est supposé, les risques de fuite temporelle, la licence et la décision.

Les analyses peuvent conserver les dépôts rejetés : cela évite de réexaminer inutilement les mêmes méthodes.
