Mon avis : une interface de recherche intéressante pour explorer des données de football et comparer plusieurs classifieurs, mais la validation décrite par le projet ne démontre pas de rentabilité. Le k-fold mélange les dates, le tuning consulte le holdout avant son évaluation, et la « Profit Balance » ne calcule pas le ROI réalisé. Je le conserve comme audit source séparé; aucune méthode distincte n'est ajoutée au catalogue et aucun code ou jeu de données tiers n'est incorporé dans les autres projets Revue.
